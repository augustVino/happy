# 国际化 (i18n) 指南

**所有用户可见字符串必须使用 `t(...)` 函数。**

## 基本用法

```typescript
import { t } from '@/text';

t('common.cancel')              // "Cancel"
t('settings.title')             // "Settings"
t('common.welcome', { name: 'Steve' })  // "Welcome, Steve!"
t('time.minutesAgo', { count: 5 })      // "5 minutes ago"
```

## 添加新翻译

1. **先检查已有 key** — 查看 `common` 或相关 section 是否已存在
2. **考虑上下文** — 根据页面/组件选择合适的 section（`settings.*`、`session.*`、`errors.*`）
3. **添加到所有语言** — `sources/text/translations/` 下所有语言文件（en, ru, pl, es, ca, it, pt, ja, zh-Hans）
4. **使用描述性 key** — `newSession.machineOffline` 优于 `msg1`

## 翻译结构

```typescript
// 静态文本
cancel: 'Cancel',

// 动态文本（带参数）
welcome: ({ name }: { name: string }) => `Welcome, ${name}!`,
itemCount: ({ count }: { count: number }) =>
    count === 1 ? '1 item' : `${count} items`,
```

## Key 分区

| 分区 | 用途 |
|------|------|
| `common.*` | 通用字符串（按钮、操作、状态） |
| `settings.*` | 设置页 |
| `session.*` | 会话管理 |
| `errors.*` | 错误消息和验证 |
| `modals.*` | 弹窗 |
| `components.*` | 组件专用 |

## 语言配置

- **`sources/text/_all.ts`** — 集中管理语言元数据：`SupportedLanguage` 类型、`SUPPORTED_LANGUAGES`、`getLanguageNativeName()` 等
- 添加新语言：更新 `_all.ts` 类型 → 添加元数据 → 创建翻译文件 → 在 `sources/text/index.ts` 中导入

## 重要规则

- JSX 中**禁止硬编码字符串**，一律用 `t('key')`
- 开发/调试页面可跳过 i18n
- 新增字符串前**先重读翻译文件**了解现有结构
- 技术术语（CLI、API、URL、JSON）保持原文
- 使用 **i18n-translator agent** 处理翻译相关工作
