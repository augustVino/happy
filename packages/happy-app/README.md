## 它是如何工作的？

在你的电脑上，运行 `happy`（替代 `claude`）或运行 `happy codex`（替代 `codex`），通过我们的封装启动你的 AI。当你想从手机控制你的代码代理时，它会以远程模式重启会话。要切回电脑端，只需在键盘上按下任意一个按键即可。

## 🔥 为什么是 Happy Coder？

- 📱 **随时通过移动端访问 Claude Code 和 Codex** - 离开工位时也能查看你的 AI 正在构建什么
- 🔔 **推送通知** - 当 Claude Code 和 Codex 需要权限或遇到错误时，会及时提醒你  
- ⚡ **一键即时切换设备** - 只需按下一次键，就能从手机或桌面端接管控制权
- 🔐 **端到端加密** - 你的代码不会以未加密的形式离开你的设备
- 🛠️ **开源** - 你可以自行审计代码。没有遥测，没有追踪

## 📦 项目组件

- **[happy-cli](https://github.com/slopus/happy-cli)** - Claude Code 和 Codex 的命令行界面
- **[happy-server](https://github.com/slopus/happy-server)** - 加密同步的后端服务器
- **happy-coder** - 这个移动端客户端（你正在使用的就是它）

## 🏠 我们是谁

我们是分散在旧金山湾区各个咖啡馆和黑客小屋里的工程师，午休时会不断查看我们的 AI 编码代理在宠爱项目上的进展。Happy Coder 源于一种挫败感：当我们离开键盘时，无法窥探我们的 AI 编码工具究竟在为我们的副业构建着什么。我们相信，最好的工具来自于“先抓住自己的痛点”，再与社区分享。
